Quick Installation

Get started with OpenDistillery in under 2 minutes. Compatible with Python 3.8+ and all major platforms. 

# Clone the repository
git clone https://github.com/llamasearchai/OpenDistillery.git
cd OpenDistillery

# Install dependencies
pip install -r requirements.txt

# Verify installation
python src/cli.py version

# Test latest AI models integration
python -c "
import sys; sys.path.insert(0, 'src')
from integrations.openai_integration import OPENAI_MODELS
print(f'Available: {len(OPENAI_MODELS)} latest OpenAI models')
print('Featured: GPT-4.1, o3, o4-mini, o3-deep-research')
"

# Run tests
pytest  # 96.5% test coverage

Usage Examples

Create powerful compound AI systems with just a few lines of code. 

# Create a compound AI system
from src.core.compound_system import SystemBuilder, SystemRequirements, SystemArchitecture

# Build system with latest models
builder = SystemBuilder()
system = builder.create_system(
    system_id="ai-research-system",
    requirements=SystemRequirements(
        domain="research",
        use_case="AI model evaluation",
        latency_target_ms=2000,
        accuracy_threshold=0.95
    ),
    architecture=SystemArchitecture.HYBRID
)

# Add latest AI models
from src.core.compound_system import ModelConfiguration

# Add GPT-4.1 for general tasks
system.add_model(ModelConfiguration(
    model_name="flagship-gpt41",
    provider="openai",
    model_id="gpt-4.1",
    specializations=["advanced_chat", "complex_tasks"]
))

# Add o3 for reasoning tasks
system.add_model(ModelConfiguration(
    model_name="reasoning-o3",
    provider="openai",
    model_id="o3",
    specializations=["complex_reasoning", "mathematical_proofs"]
))

# Process requests
result = await system.process_request({
    "task_type": "analysis",
    "content": "Analyze the latest developments in AI reasoning models",
    "reasoning_required": True
})

CLI & API Reference

Comprehensive command-line interface and RESTful APIs for all operations. 

# CLI Commands
python src/cli.py system create --system-id demo --domain research
python src/cli.py system add-model --model-id gpt-4.1 --provider openai
python src/cli.py experiment run --config experiments/reasoning.yaml
python src/cli.py server start --port 8000

# API Endpoints
curl -X POST http://localhost:8000/systems \
  -H "Content-Type: application/json" \
  -d '{
    "system_id": "financial_system",
    "domain": "finance",
    "models": [
      {"name": "gpt-4.1", "role": "primary_analyst"},
      {"name": "o3", "role": "risk_evaluator"}
    ]
  }'

# Health and metrics
curl http://localhost:8000/health
curl http://localhost:8000/metrics
